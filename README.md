# 🏗️ HERMIMETR — سیستم متره و برآورد هزینه ساخت ساختمان

پلتفرم فارسی (RTL) محاسبه دقیق هزینه ساخت مطابق بازار ایران و قوانین نظام مهندسی؛
با موتور پارامتریک متره، شاخص‌های قیمتی خودکار، زمان‌بندی اجرا و خروجی‌های حرفه‌ای.

## ویژگی‌ها

- **متره پارامتریک**: ابعاد دقیق زمین (بر×طول)، موقعیت قطعه، طبقات تجاری، نوع سقف/اسکلت، ارتفاع طبقات، سطح آب زیرزمینی و ۲۵+ فیلتر مؤثر دیگر
- **۷۵ آیتم قیمت** با تفکیک دستمزد/مصالح و منبع قیمت (فهرست بهای ابنیه / استعلام بازار / تعرفه نظام مهندسی)
- **به‌روزرسانی خودکار قیمت‌ها**: شاخص‌های زنده مصالح و دستمزد (مبنای ۲۸ آبان ۱۴۰۵) + دریفت ماهانه خودکار + پنل مدیریت
- **خروجی‌ها**: ریز اقلام با فرمول متره، لیست خرید مصالح (BOM)، شمارش نقاط تأسیساتی، گانت زمان‌بندی، منحنی نقدینگی S-Curve، چاپ PDF سربرگ‌دار، خروجی Excel/JSON
- **گزارش ماندگار**: هر برآورد با کد پیگیری در PostgreSQL ذخیره می‌شود (لینک قابل اشتراک + قابلیت ویرایش مجدد)
- **محتوای تخصصی**: راهنمای مراحل قانونی ساخت + صفحه متدولوژی شفاف

## معماری فنی

```
Next.js 16 (App Router, RSC) · TypeScript · Tailwind CSS v4 · Recharts
Drizzle ORM · PostgreSQL · Vazirmatn font
```

| مسیر | نقش |
| --- | --- |
| `src/lib/engine.ts` | موتور متره و برآورد (خالص — سمت سرور و کلاینت اجرا می‌شود) |
| `src/lib/catalog.ts` | فهرست قیمت پایه با اسکلیشن خودکار به مبنای ۱۴۰۵ |
| `src/lib/indices.ts` | سامانه شاخص‌های خودکار (مواد/دستمزد + دریفت) |
| `src/db/schema.ts` | تعریف جداول Drizzle |
| `src/app/api/*` | REST API (برآورد، گزارش‌ها، مدیریت قیمت و شاخص) |

## شروع توسعه محلی

```bash
npm ci
cp .env.example .env          # برای ذخیره گزارش‌ها DATABASE_URL را تنظیم کنید
npx drizzle-kit push --force  # اعمال اسکیمای دیتابیس
npm run dev                   # http://localhost:3000
```
